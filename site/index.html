Transcritor de Vídeo

Transforma vídeo ou áudio em texto usando o Whisper. Roda no seu computador: o arquivo não é enviado para nenhum servidor.

Arraste um vídeo ou áudio aqui ou clique para escolher (MP4, MOV, WEBM, MP3, WAV, M4A…)

O modelo é baixado só na primeira vez e fica salvo no navegador. Use Chrome ou Edge para aproveitar a placa de vídeo.
